## 0. 责任组约定（贯穿全文）

| 组 | 子系统 | 服务进程 | 交付契约 |

| A 引擎组 | AI HAL + AI Runtime | aihald | io.bianbu.AIHal |
| B 底座组 | Agent Runtime + Security | agent-runtimed, securityd | io.bianbu.Runtime, io.bianbu.Security |
| C 数据组 | Memory + 检索 | memoryd, indexerd | io.bianbu.Memory（indexerd 内部） |
| D 交互组 | Skill + Intent + Calendar | skilld, intentd, calendard | io.bianbu.Skill / .Intent / .Calendar |
| E 生态组 | Framework + SDK/CLI/接入层/App | 用户态 | SDK API / CLI 契约 / HTTP+SSE+MCP 接入层；并任"契约总集成人" |

## 附：给 aicoder / 开发者开工前必须备齐的输入（LLD 之外的配套）

LLD 完成后，开工前仍需下列配套输入，否则 aicoder 会自行拍值且各模块不一致：

1. **完整文档链且 TBD 全部回填**——凡开发路径上的 TBD 必须先定死（尤其 2/3/4/8/10）。
2. **环境与工具链基线**——worker K3、SpacemiT 定制 toolchain、bind-mount 沙箱、无 TEE 软密钥、**不复用 agentforce/hermes**（显式声明，见 AGENTS.md）。
3. **机器可读契约**——D-Bus introspection XML、SQL DDL、skill.toml/permissions.json schema、SDK 类型签名。
4. **FR→可测量验收映射 + 可运行测试骨架**——让每步可自证，避免"已完成"无依据。
