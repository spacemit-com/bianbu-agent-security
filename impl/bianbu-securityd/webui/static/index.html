🔐 安全权限设置

    
    
  

  
能力管理决定「这个 tool 能不能调」；这里决定「调用之后能碰什么」。
     执行模式由这些设置推导：声明了任何一项就走 sandbox，否则走 host（不是人指定的开关）。
     可读/可写范围都是「包含 + 排除」：
     包含项列出允许触碰的目录（每条一行），排除项列出要从其中挖掉的子目录；
     可读排除＝完全不可见，可写排除＝仍可读但不可写。网络访问范围是出站域名，
     系统调用黑名单是内核 seccomp 拒绝表，已独立成页。
